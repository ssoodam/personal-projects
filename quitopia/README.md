# QUITOPIA

> 퇴근하고 싶은 사람들의 유토피아

회사에서 소리 지를 수는 없으니까, 대신 두드려서 부숴버리는 웹사이트.
책상, 유리창, 주간 보고서, 왕젤리, 큰북, 뽁뽁이, 목탁, 3단 제빵 오븐, 회사 전화기, 디자이너 노트북, 조약돌 키보드, 불멍 라이터, 원목 토글 스위치, 알약 한 판을 두드리거나, 직접 쓴 글자를 원하는 재질로 만들어 부술 수 있다.

- **사이트**: https://quitopia-ssodam.vercel.app
- **만든 날**: 2026.11
- **역할**: 기획·디자인 디 / 구현 Claude

## 주요 기능
- 재질마다 다르게 부서짐: 나무는 쪼개지고, 유리는 창틀째 박살, 종이는 찢어지고, 젤리는 으깨짐
- 오븐은 세 칸 유리가 다 깨지며 빵까지 날아가고, 노트북은 화면이 깨지고 키캡이 쏟아지고, 회사 전화기는 수화기와 버튼이 튀어 나가며 박살
- 목탁·큰북·뽁뽁이는 아무리 두드려도 멀쩡 (목탁을 칠 때는 커서가 목탁채로 바뀜, 전화 버튼은 진짜 버튼음)
- 조약돌 키보드는 아무리 쳐도 멀쩡하고, 키캡을 기본·빵·투명·도기·젤리·이끼 중에서 고를 수 있음. 키캡마다 모양과 소리가 다름 (실제 키보드로 치면 같은 글자 키가 눌림)
- 화면 위 SIZE 바로 물건 크기를 키울 수 있음
- 직접 입력한 글자를 나무·유리·금속·젤리·종이 재질의 3D 글자로 만들어 부수기
- 두드릴 때 튀어나오는 말 직접 정하기 (POP WORDS)
- 조용 모드와 음량 조절

## 만든 방법
- three.js로 만든 3D 오브젝트, Web Audio로 만든 효과음
- 금속 질감: 직접 만든 헤어라인 스테인리스 텍스처 + cgbookcase Scratched Gold 01 노멀맵(CC0)의 잔긁힘
- 파일 하나(`index.html`)로 돌아가는 정적 사이트
